# EventoryTT — Website Design Prompt

## Role & task
You are a senior product designer and brand strategist. Design a mobile-first, high-fidelity web app prototype for **EventoryTT**, a discovery platform for deals, promotions, events and things to do in Trinidad & Tobago.

## Product rules
- EventoryTT **does not** sell, take payments, or ticket. Every offer links out to the business (website, WhatsApp, booking or ticketing page).
- Businesses submit offers via a public form (no accounts). The EventoryTT team reviews before publishing.
- Consumers never need an account. Saving deals works without login (stored on device).
- No pop-ups, fake scarcity, spin-wheels or gambling mechanics. Urgency only from real expiry dates.
- All sample offers use realistic T&T businesses, locations (e.g. Port of Spain, San Fernando, Chaguanas, Arima, Scarborough) and TTD pricing, labelled **"Demo offer — fictional"**.

## Goal
Build a daily-check habit: *"Let me check EventoryTT and see what's new today."*
Success metrics: click-throughs to businesses, WhatsApp enquiries, booking/ticket referrals, shares, return visits.

## Visual direction (from references)
- **Type:** heavy, condensed, all-caps display sans set huge and tight (stacked headlines, overlapping images); clean sans for body; prices bold and large.
- **Colour:** flat, saturated colour blocks — tomato red, sunflower yellow, lime, bubblegum pink, lilac — on a warm cream base with near-black ink. Each category owns one colour.
- **Imagery:** bright, cut-out or tightly cropped product/food photography; tilted photo cards with thick black outline and offset shadow.
- **Graphic devices:** starburst badges for discounts ("-30%", "NEW"), round sticker marks, pill-shaped outlined buttons.
- **Tone:** playful, confident, local. No tropical clichés (palms, hibiscus, sunsets), no purple SaaS gradients, no directory look.
- **Motion:** quick, tactile micro-interactions (card tilt/press, sticker pop on save, NEW badge pulse on first view).

## Core user journeys
1. **Social link → claim** (primary): Instagram/WhatsApp link → Deal page → read price, validity, how to claim → tap action (WhatsApp / Get Deal / Book / Get Tickets / Show In Store) → leaves to business. Then "More like this" pulls them into browsing.
2. **Daily check-in:** Home → "New since your last visit" strip → Today's Deals / Just Added → open deal → save or share → back to feed.
3. **Find something specific:** Home → search or category → filter (location, TTD price, verified discount, free, online/in-store, ending soon) → compare cards → deal page → claim.
4. **Plan the weekend:** Things to Do → This Weekend / Date Ideas / Free / Family → editorial collection → event or activity → Get Tickets / directions → share to group chat.
5. **Share with friends:** Any card or deal page → Share via WhatsApp (pre-filled message + deal link) → friend lands in Journey 1.
6. **Come back to saved:** Saved tab (no login) → see expiry status → claim before it ends. Optional opt-in to WhatsApp/email digest.
7. **Business submits a deal:** "Submit a Deal" → single form → confirmation explaining review & timeline → published deal page they can share.

## Screens
1. **Home** — hero with today's headline deal; New since last visit; Today's Deals; Just Added; Featured; Food; Shopping; Events; Near You; Things to Do teaser; Ending Soon.
2. **Category / browse** — category-coloured header, filter chips, sort, card grid.
3. **Search & filters** — bottom-sheet filters on mobile, sidebar on desktop, live result count.
4. **Deal detail** — large image, offer + price/was/savings, validity, claim steps, T&Cs, business info + map, primary action, WhatsApp share, related offers.
5. **Things to Do** — magazine-style editorial collections (This Weekend, Free, Date Ideas, Family, Food & Dining, Outdoors, Events, Budget).
6. **Submit a Deal** — business, contact, title, description, original/promo price, start/end dates, location, image upload, link (web/WhatsApp/booking), T&Cs; "reviewed before publishing" note.
7. **Navigation** — mobile bottom tab bar: Home · Browse · Things to Do · Saved; search always one tap away. Desktop top nav.

## Deal card (one consistent component)
Image · business name · offer title · promo price (TTD) · original price + savings (only if verified) · location · "Valid until" · NEW / Ending soon badge · save · single action button matched to offer type.

## Deliverables
- Short design system: type scale, colours, spacing, card, buttons, badges, nav, image treatment.
- Clickable prototype of the 7 screens, mobile-first with responsive desktop layouts, realistic browsing interactions (filters, save, share, navigation between pages).
